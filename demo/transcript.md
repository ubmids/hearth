# Why did you do that

Every line marked **Alexa** is the response the real server returned over HTTP, not a script.


_[Three weeks ago, during a cold snap.]_

- **Dad**: Alexa, turn it up to twenty four, it's freezing.
- **Alexa**: Noted, on Dad's word. The thermostat is set to 24 degrees. That holds only while the cold snap lasts. [e23e0e8270fe]

_[This morning.]_

- **Ada**: Alexa, make it twenty.
- **Alexa**: Noted, on Ada's word. The thermostat is set to 20 degrees. [c9eb9fbad217]
- **Alexa**: Done. The thermostat is set to 24 degrees.
- **Ada**: Alexa, why is it so warm in here?
- **Alexa**: I set the thermostat because Dad set it 3 weeks ago, during the cold snap, to 24 degrees. Ada said 20 degrees, but Dad has the say over the thermostat.

_[The cold snap ended two weeks ago. Nobody told it.]_

- **Dad**: Alexa, the cold snap is over.
- **Alexa**: Understood, the cold snap is over. The thermostat is set to 24 degrees. That no longer applies.
- **Alexa**: Done. The thermostat is set to 20 degrees.
- **Ada**: Alexa, why did you change it?
- **Alexa**: I set the thermostat because Ada set it just now, to 20 degrees.
