## No-voice fallback (captions)

If you'd rather not talk, record nothing and run the cut with `--captions`
(the command in RECORDING_PLAN.md already has it). This is what appears on
screen instead of each line:

| shot | caption on screen |
|---|---|
| hero, traffic panel | (no caption: the lower third already says "MCP traffic, live. The server refused it, not the model.") |
| why this matters | "I built Hearth for families splitting the care of a parent: a daughter with the doctor's letters, a son two states away, an aide on weekday mornings. Nobody holds the whole picture. That gap is where doses get doubled." |
| under the hood | "MCP 2025-11-25, passing the official conformance suite. And the model choosing every call is a small open one on this laptop. It doesn't need to know warfarin. Hearth does." |
| close | (no caption: the card says it) |

You can mix the two. Any memo that exists is used, and every missing line
becomes a caption.
